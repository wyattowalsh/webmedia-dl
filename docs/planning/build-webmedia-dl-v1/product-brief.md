# Product brief

## Product

**WebMedia DL** is a local-first universal media acquisition and export system for Apple devices and desktop browsers.

## Promise

> Share, paste, drop, speak, or select a source. WebMedia DL finds the media, explains the safest best-quality plan, runs it on the right device, validates the result, and keeps the original and provenance intact.

## Differentiator

The product is not merely a GUI for yt-dlp. It composes semantic extractors, image/gallery tools, browser evidence, manifest recorders, transfer engines, media processors, validation, Apple system surfaces, browser extensions, and cross-device workers behind one typed job and evidence model.

## Primary user benefit

- one action instead of tool selection;
- mixed-media page support;
- quality and semantic preservation by default;
- complete Apple-native capture and control;
- desktop browser capture across major engines;
- local privacy and no mandatory hosted backend;
- truthful failures and repairable diagnostics;
- reusable archive, derivatives, and provenance.

## Product principles

1. One-tap ordinary workflow, deep inspectability for experts.
2. The original is sacred; derivatives are explicit.
3. No silent loss, hidden cookie use, or policy bypass.
4. Provider diversity is resilience only when bounded by contracts.
5. Support claims follow executed evidence.

## Naming

- Display: **WebMedia DL**
- Repository/CLI: **`webmedia-dl`**
- Package: **`webmedia_dl`**
- Swift module prefix: **`WebMediaDL`**
- `wmdl`: optional personal alias only

Final package, domain, app-store, browser-store, and trademark checks remain a release gate.
